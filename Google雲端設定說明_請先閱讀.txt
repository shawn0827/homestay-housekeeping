民宿房務管理系統 v3｜Google Drive 安全設定說明
================================================

這一版使用：
- Google Identity Services OAuth Token Model
- Google Drive API
- 最小權限：https://www.googleapis.com/auth/drive.file
- 不使用 Client Secret
- 不保存 Google 密碼
- 不把 Access Token 寫入 localStorage
- Access Token 只保存在當次開啟 App 的記憶體中

一、更新 GitHub Pages
-------------------
1. 先備份舊版資料。
2. 將 v3 壓縮檔解壓縮。
3. 把所有檔案和 icons 資料夾上傳到原本 GitHub repository 根目錄並覆蓋。
4. Commit changes。
5. 用 Safari 開啟網站重新整理，再關閉並重開主畫面 App。

二、建立 Google Cloud 專案
------------------------
1. 開啟 Google Cloud Console。
2. 建立新專案，例如「民宿房務管理」。
3. 啟用 Google Drive API。

三、設定 OAuth 同意畫面
---------------------
1. Google Cloud Console 進入 Google Auth Platform。
2. 設定 Branding / Audience / Data Access。
3. Audience：
   - 只有自己使用時，可先選 External。
   - 若應用程式處於 Testing，請將自己的 Google 帳號加入 Test users。
4. Data Access 加入範圍：
   https://www.googleapis.com/auth/drive.file

四、建立 Web OAuth Client ID
---------------------------
1. Google Auth Platform → Clients → Create Client。
2. Application type 選 Web application。
3. Authorized JavaScript origins 加入 GitHub Pages 網站的「來源」，例如：
   https://你的帳號.github.io
   注意：這裡不含 repository 路徑，不要加最後的斜線。
4. 建立後複製 Client ID。
5. 不需要 Client Secret，也絕對不要把 Client Secret 放進 GitHub。

五、在民宿系統中連接
------------------
1. 開啟系統 → 設定。
2. 在「Google OAuth Client ID」貼上 Client ID。
3. 資料夾名稱可保留「民宿房務管理系統備份」。
4. 勾選「完成每日房務後自動同步」。
5. 按「儲存 Google 設定」。
6. 按「連接 Google Drive」並完成授權。

六、Google Drive 中會看到
-----------------------
民宿房務管理系統備份/
  房務紀錄_2026-08-01.json
  房務紀錄_2026-08-02.json
  ...
  民宿房務_最新完整備份.json

每日檔案：
- 保存該日期的完成狀態、備註、完成時間與房務清單。
- 同一天重複同步時會更新原檔，不會無限產生重複檔。

最新完整備份：
- 保存全部設定、庫存與歷史紀錄。
- 每次同步都更新同一個檔案。

七、重要限制
-----------
1. 純前端 GitHub Pages 無法在 App 完全關閉時背景同步。
2. 重新開啟 App 後，基於安全考量，可能需要重新按「連接 Google Drive」。
3. 未連線時資料仍會保存到 iPad，並列入待同步。
4. 下次連上 Google Drive 後，系統會補傳待同步日期。
5. 請勿將住宿客人的敏感個資、銀行帳號、身分證或完整聯絡資料寫進房務備註。
